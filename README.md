# DenTh

Web application for the digital management of services provided by Dentalis dental clinic.

Bachelor's degree project — based on the thesis "Computerized Management of Services Provided in a Dental Clinic" (Hîj Delia-Rut, FEAA Iași, 2023), extended with additional real-world flows for a complete, production-quality application.

## Tech Stack
- **Frontend:** React 18 + TypeScript + Vite + Tailwind CSS
- **Backend:** NestJS (TypeScript)
- **Database:** PostgreSQL + Prisma ORM
- **Real-time:** WebSockets (Socket.IO)

## Project Structure
- `/frontend` — React application
- `/backend` — NestJS API
- `/docs` — additional documentation, diagrams
